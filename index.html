Project Documentation

About This Project

Problem Statement

Traditional Indian food-preservation knowledge is passed down orally and is at risk of being lost. This project documents it digitally.

Objective

To create an accessible, well-organized digital archive of drying, fermentation, pickling and sun-drying techniques across Indian regions.

Technologies Used

HTML5, CSS3, Vanilla JavaScript, and the Groq API for the AI assistant.
